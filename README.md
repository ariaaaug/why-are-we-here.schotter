## Why We Code When Machines Can Write: A Designer's Perspective
**1. Introduction**
• The Reality: In 2026, AI can instantly generate code from natural language.
• Core Argument: We learn to code not to compete with AI on syntax, but to gain precise control over design details.
**2. Describing vs. Specifying (The Marine Interaction)**
• Natural Language is Vague (Describing): Telling AI "fish follow the mouse and produce bubbles" yields only a generic, mechanical default.
• Code is Exact (Specifying): Key details—such as the distance threshold (e.g., 50px vs. 100px) and bubble frequency—must be precisely tuned through code.
• Takeaway: Without coding knowledge, you are trapped in AI’s default settings and cannot refine subtle, lively interactions.
**3. Code as Material & Authorship**
• Code as a Medium: Just as painters understand paint, designers must understand variables and logic to debug and adapt their work freely.
• Authorship: As history shows (e.g., the invention of photography), automation does not replace artists; it shifts their role toward critical decision-making and creative direction.
**4. Conclusion**
• Summary: Machines write the code, but designers define the meaning and soul.
